===============================================================================
1. CORE ARCHITECTURE (The "Engine")
===============================================================================
The website follows a "Single Source of Truth" pattern using React Context API.

A. Inventory Context (src/context/InventoryContext.jsx)
-------------------------------------------------------
- Role: Manages all Products, Movies, and Orders.
- Firebase Sync: Uses 'onSnapshot' for real-time updates. If a product is edited 
  on one device, it reflects on all other devices instantly.
- Cloud Storage: Integrated with Firebase Storage (uploadImage) to store 
  high-quality images directly instead of relying on external links.
- Tombstone Deletion: Instead of a hard delete, it uses { deleted: true }.

B. Cart Context (src/context/CartContext.jsx)
---------------------------------------------
- Role: Manages the shopping cart and local permanence using 'localStorage'.

C. Auth Context (src/security/auth.jsx)
---------------------------------------
- Role: Handles Admin Login with fixed credentials and a 5-attempt lockout security.

===============================================================================
2. IMAGE PROCESSING & HOSTING LOGIC
===============================================================================
Location: src/utils/urlUtils.js (Function: formatImagePath)

The site uses a robust pathing system to ensure images load correctly locally and 
on GitHub Pages.

A. Environment-Agnostic Pathing:
- Logic: Checks if a path is an external link (http) or a local asset.
- Base URL Sync: Automatically prepends `import.meta.env.BASE_URL` (/Shine-Tech/).
- Double-Prefix Protection: If a path already contains the base URL (from old 
  database entries), the system detects and prevents double-prefixing.
- Dev Mode Strip: Automatically removes the production prefix when running 
  on localhost to find local files in the /public folder.

B. Firebase Storage Migration:
- New images are uploaded directly to Firebase Storage via the Dashboard.
- Secure Download URLs are stored in Firestore, ensuring 100% uptime compared 
  to deprecated Google Drive thumbnail methods.

===============================================================================
3. ADMIN PANEL LOGIC (Admin Dashboard)
===============================================================================
Location: src/pages/Dashboard.jsx

A. Advanced Image Management:
- File Upload: Forms now support direct File selection (`<input type="file">`).
- One-Click Data Cleanup: Includes a "Fix Broken Image Paths" button that 
  scans Firestore and cleans up outdated "/Shine-Tech/" prefixes automatically.

B. Simplified Interface:
- Placeholder analytics (Monthly Revenue, etc.) were removed to provide a 
  cleaner, more focused control center for movie and product management.

C. WhatsApp & Stock Sync:
- Real-time order tracking with automatic stock subtraction upon "Completion".
- One-click WhatsApp redirection for customer communication.

===============================================================================
4. BUILD & DEPLOYMENT LOGIC (GitHub Pages)
===============================================================================
File: package.json

A. Automated Build:
- npm run build:gh: Uses `vite build --base=/Shine-Tech/` to prepare the 
  production bundle with correct relative paths.

B. Manual Force Deployment:
- For the most reliable update, an "Orphan Branch" method is used:
  1. Build the project locally.
  2. Create a clean temporary branch.
  3. Force-push the built 'dist' folder to the 'gh-pages' branch.
- CLI Command: `npx.cmd gh-pages -d dist -f`
